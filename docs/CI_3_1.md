# Fase 3.1 — Integração contínua

Data da execução: 03/08/2026
Workflow: `.github/workflows/ci.yml`

## Resultado

O workflow `CI` executa o job único `quality-gates` em pull requests, pushes na
`main`, filas de merge e acionamento manual. O job usa Ubuntu e fixa Node.js
`24.18.1`, com cache do npm baseado no lockfile.

## Gates

1. `npm ci` — instalação reproduzível pelo `package-lock.json`.
2. `npm run lint` — análise ESLint.
3. `npm run typecheck` — TypeScript sem emissão de arquivos.
4. `npm test` — testes automatizados com o runner nativo do Node.js.
5. `npm run audit:ci` — falha para vulnerabilidades de severidade alta ou
   crítica.
6. `npm run build` — build estático de produção.
7. Verificação de `out/index.html`.
8. Upload do diretório `out` como artefato por sete dias.

O workflow possui permissões mínimas (`contents: read`), timeout de 20 minutos e
concorrência com cancelamento de execuções antigas da mesma referência.

## Testes automatizados iniciais

`tests/project.test.mjs` valida:

- configuração obrigatória do export estático do Next.js;
- correspondência entre manifest e lockfile;
- ausência de credenciais administrativas do Supabase no cliente público e no
  workflow.

## Variáveis públicas de build

O build utiliza somente valores públicos: URL do projeto Supabase, placeholder
de chave pública e site key do Turnstile. Nenhuma `service_role`, secret key ou
credencial da Hostinger é fornecida à CI.

## Proteção da branch

A tentativa de consultar/configurar a proteção da `main` pela API retornou HTTP
403: o GitHub exige upgrade para Pro ou que o repositório seja público. Portanto,
os requisitos de uma aprovação e do check `quality-gates` obrigatório ainda não
podem ser aplicados ao repositório privado no plano atual.

Para concluir essa parte após liberar o recurso, configure uma regra para
`main` com:

- pull request obrigatório;
- uma aprovação obrigatória;
- dispensa de aprovações antigas quando houver novos commits;
- check obrigatório `quality-gates`;
- branch atualizada antes do merge;
- conversas resolvidas antes do merge.
